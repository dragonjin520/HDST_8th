# 따릉이 재배치 운영 대시보드 Product Flow

## 1. 데이터 프로덕트 정의

따릉이 대여소의 현재 자전거 수와 향후 12시간의 대여·반납 수요를 예측하여, 공급 또는 회수가 필요한 대여소를 조기에 탐지하고 지통실 운영자의 배치기사 파견 의사결정을 지원하는 재배치 운영 대시보드다.

이 시스템은 평상시의 고정 관리 루트를 완전히 대체하는 것이 아니라, 급격한 수요 변화나 공급 불균형이 예상되는 예외 상황을 빠르게 감지해 추가 파견 여부를 판단하도록 지원한다.

---

## 2. 주요 사용자

### 지통실 운영자

- 전체 대여소의 현재 상태를 지도에서 확인한다.
- 공급 또는 회수가 필요한 대여소를 확인한다.
- 작업 발생까지 남은 시간과 필요 수량을 확인한다.
- 수요 변화의 근거를 검토한다.
- 배치기사 파견 여부를 결정한다.

### 배치기사

- 평상시에는 고정 경로를 따라 대여소를 관리한다.
- 긴급 수요 또는 과잉 공급이 발생하면 지통실의 지시에 따라 추가 파견된다.
- 공급 또는 회수 작업을 수행한다.

---

## 3. 운영 흐름

```text
대여소 상태 및 수요 변화 감지
→ 긴급 작업이 필요한 대여소 선별
→ 지통실 대시보드에 우선순위 표시
→ 운영자가 상세 원인과 예상 시간을 확인
→ 배치기사 파견
→ 자전거 공급 또는 회수
```

평상시에는 배치기사가 고정 루트를 운행한다.

시스템은 다음과 같은 상황에서 별도 작업을 생성한다.

- 특정 대여소의 자전거 부족이 예상되는 경우
- 자전거가 과도하게 몰려 반납 공간 부족이 예상되는 경우
- 침수, 강우, 폭염 등 날씨 위험이 예상되는 경우
- 실시간 인구 또는 행사로 인해 평소와 다른 수요 급증이 예상되는 경우

## 5. 지도 기반 대여소 상태

지도에는 각 대여소의 현재 상태와 예측 상태를 함께 표시한다.

| 상태 | 표시 | 의미 |
|---|---|---|
| 정상 | 기본 색상 | 별도 작업이 필요하지 않음 |
| 공급 필요 | 빨간색 | 향후 자전거 부족이 예상됨 |
| 회수 필요 | 파란색 | 자전거 과잉 또는 거치 공간 부족이 예상됨 |
| 긴급 | 강조 테두리 또는 아이콘 | 제한 시간 내 작업이 필요함 |

현재 자전거 수와 미래 수요를 구분해 판단한다.

예를 들어 현재 자전거가 충분해 보여도 퇴근 시간대에 수요가 급증할 것으로 예상되면 공급 필요 상태로 표시한다.

```text
현재 자전거 수: 10대
향후 1시간 예상 대여: 18대
향후 1시간 예상 반납: 3대

예상 잔여량
= 10 - 18 + 3
= -5대

→ 공급 필요
```

## 6. 예측 실행 방식

시스템은 1시간마다 최신 데이터를 기준으로 수요 예측을 다시 계산한다.

예측 범위는 각 실행 시점으로부터 향후 12시간이다.

```text
현재 시각 14:00
→ 14:00에 모델 실행
→ 15시부터 다음 날 02시까지 예측

15:00
→ 최신 인구, 날씨, 자전거 수 반영
→ 다시 향후 12시간 예측
```

### 예측 입력 데이터

- 과거 대여 이력
- 과거 반납 이력
- 현재 대여소 자전거 수
- 대여소 수용량
- 실시간 인구
- 날씨 관측 및 예보
- 시간대와 요일
- 주말 및 공휴일 여부
- 선택적으로 인근 행사 일정

### 예측 결과

- 시간대별 예상 대여량
- 시간대별 예상 반납량
- 시간대별 예상 잔여 자전거 수
- 자전거 부족 예상 시각
- 거치 공간 포화 예상 시각
- 공급 또는 회수 필요 수량

---

## 7. 공급 및 회수 판단

### 공급 작업

향후 수요를 감당하기에 자전거가 부족한 경우다.

```text
현재 자전거 수
- 예상 대여량
+ 예상 반납량
< 최소 안전 재고
```

화면에는 다음 정보를 제공한다.

- 공급 필요 수량
- 부족 예상 시각
- 부족 상태 예상 지속 시간
- 주변 자전거 여유 대여소
- 후보 대여소까지의 거리

### 회수 작업

향후 자전거가 과도하게 몰리거나 반납 공간이 부족해지는 경우다.

```text
현재 자전거 수
- 예상 대여량
+ 예상 반납량
> 대여소 수용량 - 안전 여유 공간
```

회수 작업의 주요 사유는 다음과 같다.

- 과잉 반납 예상
- 거치대 포화 예상
- 침수 위험
- 운영 중단 예정
- 안전 문제

화면에서는 작업 종류와 작업 사유를 구분해 표시한다.

```text
작업 종류: 회수
작업 사유: 거치대 포화 예상
```

또는

```text
작업 종류: 회수
작업 사유: 침수 위험
```

## 8. 긴급 작업 목록

우측 리스트에는 작업이 필요한 대여소를 긴급한 순서대로 나열한다.

### 기본 정렬 기준

```text
1차 정렬: 위험 발생까지 남은 시간 오름차순
2차 정렬: 필요한 이동 수량 내림차순
```

예시:

| 우선순위 | 대여소 | 작업 | 예상 발생 시각 | 남은 시간 | 필요 수량 |
|---:|---|---|---:|---:|---:|
| 1 | 강남역 2번 출구 | 공급 | 18:00 | 35분 | 12대 |
| 2 | 잠실야구장 앞 | 회수 | 18:30 | 1시간 5분 | 8대 |
| 3 | 여의도공원 | 공급 | 19:00 | 1시간 35분 | 6대 |

```text
남은 시간
= 위험 발생 예상 시각
- 현재 시각
```

향후에는 다음 요소를 결합한 긴급도 점수로 확장할 수 있다.

- 위험 발생까지 남은 시간
- 예상 부족 또는 과잉 수량
- 위험 지속 시간
- 대여소 중요도

---

## 9. 대여소 선택 인터랙션

사용자가 지도 또는 긴급 작업 목록에서 대여소를 선택하면 다음 동작이 발생한다.

```text
대여소 선택
→ 지도에서 해당 대여소 강조
→ 좌측 하단에 12시간 수요 예측 그래프 표시
→ 우측 하단에 상세 정보 표시
→ 공급 필요 시 주변 여유 대여소 표시
→ 회수 필요 시 이동 가능한 인근 대여소 표시
```

---

## 10. 향후 12시간 수요 예측 그래프

좌측 하단 그래프에는 다음 정보를 함께 표시한다.

- 예상 대여량
- 예상 반납량
- 예상 자전거 잔여량
- 대여소 수용량
- 최소 안전 재고
- 위험 발생 예상 시점

예시:

| 시간 | 15시 | 16시 | 17시 | 18시 | 19시 |
|---|---:|---:|---:|---:|---:|
| 예상 대여량 | 3 | 5 | 8 | 15 | 11 |
| 예상 반납량 | 4 | 4 | 5 | 3 | 4 |
| 예상 잔여량 | 18 | 17 | 14 | 2 | -5 |

위 예시에서는 18시부터 부족 위험이 발생하고, 19시에는 수요를 충족하지 못할 가능성이 커진다.

## 11. 대여소 상세 정보

우측 하단 상세 정보 영역에는 다음 내용을 표시한다.

| 항목 | 예시 |
|---|---|
| 현재 자전거 수 | 12대 |
| 대여소 수용량 | 20대 |
| 예상 부족 시각 | 18:20 |
| 공급 필요 수량 | 8대 |
| 위험 지속 시간 | 약 2시간 |
| 작업 종류 | 공급 |
| 주요 근거 | 퇴근 시간대, 인구 증가, 맑은 날씨 |
| 추천 공급처 | 인근 A·B 대여소 |
| 예측 신뢰도 | 보통 또는 82% |

## 12. 주변 대여소 추천

공급 필요 대여소를 선택하면 주변의 자전거 여유 대여소를 함께 표시한다.

```text
공급 필요 대여소 선택
→ 주변 대여소 검색
→ 현재 자전거 수 확인
→ 해당 대여소의 향후 수요 확인
→ 이동 가능한 자전거 수 계산
→ 거리순 또는 추천순 표시
```

현재 자전거 수만 많은 대여소가 아니라, 향후 수요를 고려해 자전거를 빼도 되는 대여소를 추천해야 한다.

```text
이동 가능 수량
= 현재 자전거 수
- 해당 대여소의 예상 필요량
- 안전 재고
```

예시:

```text
A 대여소 현재 자전거: 30대
향후 예상 필요량: 18대
안전 재고: 5대

이동 가능 수량
= 30 - 18 - 5
= 7대
```

추천 목록에는 다음 정보를 표시한다.

- 후보 대여소 이름
- 현재 자전거 수
- 이동 가능 수량
- 대상 대여소까지 거리
- 후보 대여소의 향후 부족 위험 여부

## 13. 수요 변화 근거

시스템은 수요 증가 또는 감소 결과만 보여주는 것이 아니라, 예측에 영향을 준 주요 근거를 함께 표시한다.

예시:

```text
수요 증가 예상 근거
1. 평소 금요일 18시 대여량이 평균보다 42% 높음
2. 해당 지역 실시간 인구가 평소보다 28% 증가
3. 18시부터 강수 확률이 낮아 자전거 이용에 유리
4. 인근 야구장에서 17시 30분 경기 종료 예정
```

### 정기적인 시간 패턴

- 출근 시간
- 퇴근 시간
- 요일
- 주말
- 공휴일

### 실시간 및 예보 데이터

- 실시간 인구 급증
- 강우
- 폭염
- 강풍
- 한파

### 외부 이벤트

- 프로야구 경기
- 콘서트
- 축제
- 집회
- 대규모 행사

이벤트 기능을 구현하려면 다음 외부 데이터가 추가로 필요하다.

```text
공연·스포츠·축제 일정 데이터
→ 행사 장소 좌표
→ 행사 시작·종료 시각
→ 예상 또는 실제 방문 인원
→ 인근 대여소 매핑
```

초기 MVP에서는 시간대, 날씨, 실시간 인구 근거를 우선 제공하고 이벤트 데이터는 확장 기능으로 적용한다.

## 14. 핵심 입력과 출력

### 입력

```text
과거 대여·반납 이력

실시간 인구

대여소 위치 및 수용량

```


## 15. MVP 범위

### 1차 구현

- 현재 대여소 상태 지도 표시
- 공급 필요 대여소 빨간색 표시
- 회수 필요 대여소 파란색 표시
- 1시간 주기 예측 결과 갱신
- 향후 12시간 대여·반납 수요 그래프
- 긴급 작업 목록
- 작업 발생까지 남은 시간 표시
- 시간대, 요일, 날씨, 실시간 인구 기반 변화 근거 표시

### 2차 구현

- 주변 여유 대여소 추천
- 이동 가능 자전거 수 계산
- 공급·회수 수량 추천
- 대여소별 안전 재고 적용
- 위험 지속 시간 계산

### 확장 기능

- 행사 일정 데이터 연동
- 침수 위험 데이터 연동
- 배치기사 경로 추천
- 작업 배정 및 처리 상태 관리
- 실제 작업 결과를 통한 예측 및 추천 성능 평가

## 16. 핵심 가치

이 시스템은 단순히 수요가 높은 대여소를 보여주는 것이 아니다.

```text
현재 상태 확인
→ 미래 위험 예측
→ 작업 필요 시점과 수량 제시
→ 변화 근거 설명
→ 주변 대여소 추천
→ 지통실의 배치기사 파견 판단 지원
```

즉, 분석 결과를 실제 재배치 업무로 연결하는 운영 의사결정 지원 데이터 프로덕트다.
